Start with the big picture

Two readings, one shared idea

Both sections are about getting useful structure from limited information. A mixture model says that one visible population may be produced by several hidden subpopulations. Bias-variance analysis says that a slightly constrained estimate may be more reliable than a perfectly flexible one.

Hidden sourceA latent variable chooses which component generated an observation.
Uncertain assignmentA responsibility gives each component partial credit for a data point.
Controlled flexibilityShrinkage adds bias but can reduce variance and total squared error.
The connection: mixture models introduce hidden structure to explain complex data; regularization introduces structure to stabilize an estimate. In both cases, assumptions can help when they are well chosen and hurt when they are wrong.

3.5 · Mixture models

Build a complicated density from simple pieces

A mixture model combines (K) component distributions with nonnegative weights that sum to one:

\[p(y\mid\theta)=\sum_{k=1}^{K}\pi_k p_k(y),\qquad \pi_k\ge0,\quad \sum_{k=1}^{K}\pi_k=1\] This is a convex combination: at every value of (y), the final density is a weighted average of the component densities.

The same model can be written with a discrete latent variable (Z\in\{1,\ldots,K\}):

\[p(z=k\mid\theta)=\pi_k,\qquad p(y\mid z=k,\theta)=p(y\mid\theta_k)\] \[p(y\mid\theta)=\sum_{k=1}^{K}p(z=k\mid\theta)p(y\mid z=k,\theta)\] We do not observe (Z). We only observe (Y), so we marginalize the hidden choice away.
  1. Choose a component. Draw (Z\) from a categorical distribution with probabilities (pi_1,\ldots,\pi_K).
  2. Generate the observation. Draw (Y) from the selected component (p(y\mid\theta_Z)).
  3. Hide the component label. The learner sees (Y), but must infer which (Z) probably produced it.

3.5.1 · Posterior component identity

Responsibility is Bayes’ rule inside the mixture

After observing (y_n), we reverse the generative story and ask which component most likely produced it. The posterior probability is called the responsibility of component (k) for point (n):

\[r_{nk}=p(z_n=k\mid y_n,\theta)=\frac{\pi_k p(y_n\mid z_n=k,\theta)}{\sum_{k'=1}^{K}\pi_{k'}p(y_n\mid z_n=k',\theta)}\] Prior weight × component likelihood, normalized across all components.

3.5.1 · Gaussian mixture models

A GMM turns ellipses into clusters

\[p(\mathbf y\mid\theta)=\sum_{k=1}^{K}\pi_k\,\mathcal N(\mathbf y\mid\mu_k,\Sigma_k)\]

Each Gaussian component contributes a center, a covariance shape, and a mixture weight. With enough components, a GMM can approximate a wide range of smooth densities. For clustering, the latent component identity becomes a cluster label.

3.5.2 · Bernoulli mixture models

The components do not have to be Gaussian

For a binary vector (mathbf y\in\{0,1\}^D), a Bernoulli mixture uses an independent Bernoulli distribution for each bit within each component:

\[p(\mathbf y\mid z=k,\theta)=\prod_{d=1}^{D}\mu_{dk}^{y_d}(1-\mu_{dk})^{1-y_d}\] (mu_{dk}) is the probability that bit (d) is on in component (k).

What a component represents

A vector of probabilities, not one fixed binary image. High-probability pixels form a prototype, while uncertain pixels may switch on or off.

Why it can discover digits

Different components specialize in recurring binary patterns. No digit labels are required, so this is unsupervised learning.

Conditional independence is an assumption. Within one Bernoulli component, the bits are independent given (Z). Dependence in the overall data is created by mixing components. If the true within-cluster structure is richer, the model may need more components than the number of semantic classes.

4.7.6 · Bias and variance

An estimator is random before the data arrive

An estimator (hat\theta(\cdot)) is a procedure. Once we feed it a particular dataset (D), it returns the estimate (hat\theta(D)). If nature repeatedly draws new datasets, the estimate changes, producing a sampling distribution.

BiasWhere the sampling distribution is centered relative to the truth.
VarianceHow much the estimate changes from one dataset to another.
MSEThe average squared distance between the estimate and truth.
\[\operatorname{bias}(\hat\theta)=\mathbb E[\hat\theta]-\theta^*\qquad \operatorname{Var}(\hat\theta)=\mathbb E[\hat\theta^2]-\mathbb E[\hat\theta]^2\]

Unbiased does not automatically mean good. The estimator that uses only the first observation, (hat\theta(D)=x_1), is unbiased for a Gaussian mean, but it is much noisier than the sample mean.

The (N) versus (N-1) variance estimator

When the mean is estimated from the same data, the Gaussian maximum-likelihood variance estimator is slightly biased downward:

\[\hat\sigma^2_{\mathrm{MLE}}=\frac1N\sum_{n=1}^{N}(x_n-\bar x)^2,\qquad \mathbb E[\hat\sigma^2_{\mathrm{MLE}}]=\frac{N-1}{N}\sigma^2\] \[\hat\sigma^2_{\mathrm{unb}}=\frac1{N-1}\sum_{n=1}^{N}(x_n-\bar x)^2\] Estimating (\bar x) uses one degree of freedom. Dividing by (N-1) corrects the average downward bias.

4.7.6.3 · Squared-error decomposition

Low bias and low variance compete

\[\mathbb E[(\hat\theta-\theta^*)^2]=\operatorname{Var}(\hat\theta)+\operatorname{bias}(\hat\theta)^2\] For parameter estimation under squared error: MSE = variance + squared bias.

A biased estimator can be better if the variance reduction is larger than the squared bias it introduces. This is the logic behind shrinkage, regularization, and many ensemble methods.

4.7.6.4–4.7.6.5 · MAP and regularization

Shrinkage trades a little accuracy for stability

Suppose (x_n\sim\mathcal N(\theta^*,\sigma^2)). The sample mean is the MLE. A Gaussian prior centered at (\theta_0) produces a MAP estimate that averages the data and prior:

\[\tilde x=w\bar x+(1-w)\theta_0,\qquad 0\le w\le1\] \[\operatorname{bias}(\tilde x)=(1-w)(\theta_0-\theta^*),\qquad \operatorname{Var}(\tilde x)=w^2\frac{\sigma^2}{N}\] (w=1) gives the MLE. Smaller (w) trusts the prior more strongly.

Ridge regression uses the same principle in many dimensions: a zero-mean Gaussian prior pulls coefficients toward zero. Stronger regularization makes fitted curves more similar across datasets, reducing variance, but it can also pull the average fit away from the truth, increasing bias.

Classification caveat: under 0–1 loss, risk does not decompose into variance plus squared bias. The interaction can be multiplicative, and more variance can sometimes help when an estimate lies on the wrong side of the decision boundary. For classification, focus on expected loss, usually estimated with cross-validation.

Final recap: take these eight ideas with you

  • A mixture density is a weighted sum of simpler component densities.
  • The latent variable (Z) records which component generated an observation.
  • Responsibilities are posterior component probabilities computed with Bayes’ rule.
  • Soft clustering keeps uncertainty; hard clustering keeps only the most likely component.
  • GMMs model continuous data; Bernoulli mixtures model binary vectors.
  • Bias measures systematic displacement; variance measures sensitivity to the sampled dataset.
  • Under squared error, MSE equals variance plus squared bias.
  • Shrinkage and regularization can improve MSE by exchanging some bias for a larger variance reduction.
