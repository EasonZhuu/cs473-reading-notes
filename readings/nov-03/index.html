SVM 的概率、调参与稀疏模型SVM Probabilities, Tuning, and Sparse Models

SVM 的分数不是天然概率；hinge loss 把间隔转成优化目标。多分类需要组合二分类器，RBF 的 \(C\) 与 \(\gamma\) 要一起调。稀疏向量机则在预测速度、概率输出和优化难度之间做权衡。

An SVM score is not automatically a probability. Hinge loss turns the margin into an optimization objective. Multiclass prediction combines binary classifiers, RBF \(C\) and \(\gamma\) must be tuned together, and sparse vector machines trade prediction speed against probability output and optimization difficulty.

Kevin P. Murphy · Probabilistic Machine Learning: An Introduction · printed pp. 591–601 (through Table 17.1) · PDF pp. 621–631 (before §17.5)

ONE IDEA / 一个核心想法

把“分数、概率、稀疏”分清楚Keep scores, probabilities, and sparsity distinct

Score \(\ne\) probability / 分数不等于概率

SVM 的 \(f(x)\) 定义了边界和置信方向；除非另外校准，不能把它当成 log-odds。

The SVM score \(f(x)\) defines the boundary and direction of confidence; it is not a log-odds value unless calibrated separately.

Margin loss / 间隔损失

hinge loss 惩罚错误和间隔不足；达到规范 margin 后损失为零。

Hinge loss penalizes mistakes and insufficient margin, then becomes exactly zero once the normalized margin is reached.

Sparse predictors / 稀疏预测

只保留少数训练样本能加快预测；概率校准、核调参和优化性质仍各有差异。

Keeping only a few training examples can speed prediction; probability calibration, kernel tuning, and optimization properties still differ by method.

17.3.5 · CONVERTING SVM OUTPUTS INTO PROBABILITIES

SVM 分数要经过校准，才有概率含义An SVM score needs calibration before it means a probability

二分类 SVM 输出 \(f(x)\)，标签由 \(\hat y=\mathrm{sign}(f(x))\) 决定。一个常见启发式是把 \(f(x)\) 当作 log-odds，再用 sigmoid 映射到 \([0,1]\)。但这只是后处理：SVM 的训练目标没有保证分数是 log-odds，所得概率也可能校准不佳。

A binary SVM outputs \(f(x)\), with label \(\hat y=\mathrm{sign}(f(x))\). A common heuristic treats \(f(x)\) as log-odds and maps it through a sigmoid. This is post-processing: the SVM objective does not make its score a log-odds value, so the resulting probabilities may be poorly calibrated.

\[p(y=1\mid x,\theta)=\sigma(af(x)+b),\qquad \sigma(z)=\frac{1}{1+e^{-z}}\]

Platt scaling 在独立验证集上用最大似然估计 \(a,b\)。若在训练集拟合它们，教材提醒会严重过拟合。

Platt scaling estimates \(a,b\) by maximum likelihood on a separate validation set. Fitting them on the training set can severely overfit, as the text warns.

校准不是分类准确率。教材的均匀分布例子中，SVM 与 RVM 都能达到 Bayes 最优的 25% 泛化错误率；但 RVM 概率更接近真实 log-odds，SVM 分数并不因此自动校准。

Calibration is not classification accuracy. In the textbook's uniform-distribution example, both the SVM and RVM reach the Bayes-optimal 25% generalization error, yet the RVM probability better tracks the true log-odds. The SVM score is not automatically calibrated.

17.3.6 · CONNECTION WITH LOGISTIC REGRESSION

Hinge 与 logistic 都替代 0–1 错误Hinge and logistic losses both surrogate 0–1 error

令 \(\tilde y\in\{-1,+1\}\)，\(\eta=f(x)\)，signed margin 为 \(m=\tilde y\eta\)。SVM 的 hinge loss 只在 \(m<1\) 时为正；logistic loss 则随 margin 平滑下降。两者都是凸的 0–1 loss 上界，便于优化，但形状和诱导出的稀疏性不同。

Let \(\tilde y\in\{-1,+1\}\), \(\eta=f(x)\), and signed margin \(m=\tilde y\eta\). Hinge loss is positive only for \(m<1\); logistic loss decreases smoothly with the margin. Both are convex upper bounds on 0–1 loss and are easier to optimize, but their shapes and sparsity behavior differ.

\[\ell_{\mathrm{hinge}}(\tilde y,\eta)=\max(0,1-\tilde y\eta),\qquad \ell_{\mathrm{log}}(\tilde y,\eta)=\log(1+e^{-\tilde y\eta})\]

教材给出的 SVM 目标可写作 \(\sum_n\ell_{\rm hinge}+\lambda\lVert w\rVert^2\)，其中 \(\lambda=(2C)^{-1}\)。hinge 的零损失区使许多样本不再影响解；logistic loss 平滑，但有限 margin 下不变成严格的零。

The text writes the SVM objective as \(\sum_n\ell_{\rm hinge}+\lambda\lVert w\rVert^2\), with \(\lambda=(2C)^{-1}\). Hinge loss has a zero-loss region, so many examples stop affecting the solution; logistic loss is smooth but is not exactly zero at any finite margin.

17.3.7 · MULTI-CLASS CLASSIFICATION WITH SVMs

多分类要组合多个二分类器Multiclass prediction combines binary classifiers

SVM 原生是二分类器。One-versus-rest (OvR) 训练 \(K\) 个模型，每个模型区分一个类和其余类，最后常用 \(\arg\max_c f_c(x)\)。独立模型可能同时判正，也可能都判负；分数未校准，不能天然比较，而且类别不平衡会影响每个子问题。

An SVM is natively binary. One-versus-rest (OvR) trains \(K\) models, each separating one class from the rest, and often predicts with \(\arg\max_c f_c(x)\). Independent models can all be positive or all negative; scores are not calibrated for comparison, and class imbalance can hurt each subproblem.

One-versus-one (OvO) 为每一对类别训练一个分类器，共 \(K(K-1)/2\) 个，再按多数票决定类别。它避开 OvR 的单类对“其余所有类”结构，却要存储 \(O(K^2)\) 个模型，投票也可能平票。

One-versus-one (OvO) trains one classifier for every class pair, for \(K(K-1)/2\) models, then uses majority voting. It avoids OvR's one-class-versus-everything-else setup, but stores \(O(K^2)\) models and votes can tie.

\[\text{OvR: }K\text{ classifiers}\qquad\qquad \text{OvO: }\binom{K}{2}=\frac{K(K-1)}{2}\text{ classifiers}\]

17.3.8 · HOW TO CHOOSE THE REGULARIZER C

\(C\) 与 RBF 的 \(\gamma\) 要联合选择Choose \(C\) jointly with the RBF \(\gamma\)

通常用交叉验证选择 \(C\)，但它与 kernel 参数强耦合。RBF kernel 写作 \(K(x,x')=\exp(-\gamma\lVert x-x'\rVert^2)\)，其中 \(\gamma=1/(2\sigma^2)\)。\(\gamma\) 大代表窄核，常需更强正则化（较小 \(C\)）；\(\gamma\) 小代表宽核，可能搭配较大 \(C\)。应在二维网格中一起做 CV。

Cross-validation typically selects \(C\), but it is strongly coupled to kernel parameters. An RBF kernel is \(K(x,x')=\exp(-\gamma\lVert x-x'\rVert^2)\), where \(\gamma=1/(2\sigma^2)\). Large \(\gamma\) means narrow kernels and may call for heavier regularization (smaller \(C\)); small \(\gamma\) means broader kernels and may pair with larger \(C\). Tune both on a two-dimensional CV grid.

教材的示例在 two-moons 数据上比较 \(C\) 与 \(\gamma\)，并展示交叉验证错误率面。下面用可运行的简化 SMO 训练一个小型 RBF 软间隔 SVM；数据是确定性玩具样本，不是教材图 17.17 的复刻。边界形状随两参数共同变化。

The text compares \(C\) and \(\gamma\) on two-moons data and shows a cross-validation error surface. The interactive demo below trains a small RBF soft-margin SVM with simplified SMO. Its deterministic toy data do not reproduce Figure 17.17; the decision boundary illustrates the joint effect of the two parameters.

17.4 · SPARSE VECTOR MACHINES

稀疏核模型能省预测成本，但性质不同Sparse kernel models save prediction work, but differ in other ways

高斯过程 (GP) 很灵活，但预测常需 \(O(N)\) 个训练样本相似度。SVM 用稀疏系数减少预测所需样本，却不直接输出校准概率。另一种路径是把每个训练样本做成一个 kernel basis：\(\phi(x)=[K(x,x_1),\ldots,K(x,x_N)]\)，再拟合 logistic regression 等判别模型。

Gaussian processes (GPs) are flexible, but prediction often uses \(O(N)\) training-point similarities. SVMs reduce the number of examples needed at prediction time, but do not directly produce calibrated probabilities. Another route makes each training example a kernel basis, \(\phi(x)=[K(x,x_1),\ldots,K(x,x_N)]\), then fits a discriminative model such as logistic regression.

17.4.1 · RELEVANCE VECTOR MACHINES

RVM 用 ARD 寻找相关样本RVM uses ARD to find relevant examples

L2VM 用 \(\ell_2\) 正则化，通常权重稠密；L1VM 用 \(\ell_1\)/Laplace prior 鼓励稀疏；RVM 用 ARD（type-II maximum likelihood / empirical Bayes）估计稀疏权重。RVM 往往稀疏得更强，但优化目标非凸。

L2VM uses \(\ell_2\) regularization and usually has dense weights; L1VM uses \(\ell_1\)/a Laplace prior to encourage sparsity; RVM uses ARD (type-II maximum likelihood / empirical Bayes) to estimate sparse weights. RVMs are often more sparse, but their objective is nonconvex.

TAKEAWAYS / 最后记住

把选择逻辑串起来Put the choices together

SVM 分数可用 Platt scaling 映射成概率，但必须在独立验证集上校准；hinge 是凸的 margin surrogate，OvR/OvO 将二分类扩展到多类；RBF 的 \(C\) 与 \(\gamma\) 需联合交叉验证。稀疏方法以较少样本预测换取速度，RVM 以非凸经验贝叶斯优化换取更强稀疏性；SVM/GP 需要 Mercer kernel。

Platt scaling can map SVM scores to probabilities, but calibrate on a separate validation set. Hinge is a convex margin surrogate; OvR/OvO extend binary models to multiple classes; RBF \(C\) and \(\gamma\) need joint cross-validation. Sparse methods trade fewer prediction examples for speed; RVM trades convexity for stronger sparsity through empirical Bayes. SVMs and GPs require Mercer kernels.
