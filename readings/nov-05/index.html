树模型与集成学习Trees and Ensemble Learning

CART 用递归切分把输入空间划成局部区域，再在叶节点给出预测。贪心生长容易过拟合也容易不稳定；控制树深度能管住复杂度，而组合多种预测可降低方差。集成权重、stacking 与 Bayesian model averaging 需要分清。

CART recursively partitions the input space and predicts locally at each leaf. Greedy growth can overfit and be unstable; limiting tree complexity controls that behavior, while combining predictions can reduce variance. Ensemble weights, stacking, and Bayesian model averaging must be distinguished.

Kevin P. Murphy · Probabilistic Machine Learning: An Introduction · online edition Apr 18, 2025 · printed pp. 603–609 · PDF pp. 633–639

ONE IDEA / 一个核心想法

从局部规则，到稳定的整体预测From local rules to a steadier combined prediction

Partition / 切分

树按特征和阈值反复分割空间；每个叶子对应一块区域和一个局部预测。

A tree repeatedly splits the space by feature and threshold; each leaf represents a region and a local prediction.

Greedy growth / 贪心生长

每一步挑当前最好的切分，再递归处理子集；简单、快，但不是全局最优搜索。

Each step chooses the best current split and recurses on the subsets. It is simple and fast, but not a global search.

Aggregate / 集成

多模型平均或投票能抵消一部分波动；收益依赖模型间的错误不完全相同。

Averaging or voting can cancel some fluctuations; the gain depends on models making nonidentical errors.

18.1 · CLASSIFICATION AND REGRESSION TREES

一棵树就是一组嵌套的 if–then 规则A tree is a set of nested if–then rules

节点 \(i\) 选一个特征 \(d_i\) 和阈值 \(t_i\)，按 \(x_{d_i}\le t_i\) 或 \(x_{d_i}>t_i\) 走向左右子树。沿根到叶的规则定义区域 \(R_j\)。这些切分通常与坐标轴平行；分类特征也可按“等于某值 / 不等于某值”二分。

At node \(i\), the tree chooses a feature \(d_i\) and threshold \(t_i\), then branches on \(x_{d_i}\le t_i\) versus \(x_{d_i}>t_i\). The root-to-leaf rules define region \(R_j\). Splits are usually axis-parallel; a categorical feature can also be split by “equals this value” versus “does not.”

\[f(x;\theta)=\sum_{j=1}^{J}w_j\,\mathbb{I}(x\in R_j),\qquad w_j=\frac{\sum_n y_n\mathbb{I}(x_n\in R_j)}{\sum_n\mathbb{I}(x_n\in R_j)}\]

回归树在叶子输出该区域训练目标的均值，因此预测在每块区域内是常数。分类树则在叶子存经验类别分布 \(\hat\pi_{jc}\)，通常用最大概率类别做预测。

A regression leaf predicts the mean target of its training examples, so its output is constant within each region. A classification leaf stores an empirical class distribution \(\hat\pi_{jc}\), typically predicting the most probable class.

18.1.2 · GREEDY MODEL FITTING

每次选一个让子节点加权损失最低的切分Choose each split to minimize weighted child loss

联合选择整棵树的离散结构很难；教材指出最优分区问题是 NP-complete。CART 等方法因此贪心地生长：在当前节点，枚举候选特征和阈值，让左右孩子的加权代价最低，然后对子节点重复。

Jointly choosing the discrete structure of an entire tree is hard; the text notes that optimal partitioning is NP-complete. CART and related methods therefore grow greedily: at the current node, consider candidate features and thresholds, minimize the weighted cost of the two children, and repeat.

\[(j_i,t_i)=\arg\min_{j,t}\left[\frac{|D_i^L(j,t)|}{|D_i|}c(D_i^L)+\frac{|D_i^R(j,t)|}{|D_i|}c(D_i^R)\right]\]

连续特征的候选阈值来自排序后的观测值；分类特征可做类别对剩余类别的二分。若对类别做多路切分，数据可能被分散到太小的分支，形成 data fragmentation 并过拟合。

Candidate thresholds for continuous features come from sorted observed values; a categorical feature can split one value from the rest. Multiway splits can fragment the data into tiny branches, leading to overfitting.

Regression · MSE

\(c(D_i)=|D_i|^{-1}\sum_{n\in D_i}(y_n-\bar y_i)^2\)

节点内用目标均值预测，再计算平方误差。Predict the node mean and measure squared error.
Classification · Gini

\(G_i=1-\sum_c\hat\pi_{ic}^{\,2}\)

类别越混杂，Gini 越大；纯节点为 0。More mixed class proportions give higher Gini; a pure node has 0.
Classification · Entropy

\(H_i=-\sum_c\hat\pi_{ic}\log\hat\pi_{ic}\)

另一种不纯度；纯节点同样为 0。Another impurity measure; a pure node also has 0.

18.1.3–18.1.5 · REGULARIZATION, MISSING INPUTS, PROS AND CONS

深树会记住训练集；剪枝与验证控制复杂度Deep trees can memorize; pruning and validation control complexity

足够深的树可以把训练误差压到 0，却可能过拟合。预剪枝在生长时限制深度或要求节点至少有一定样本数；后剪枝先长到很深，再把分裂子树合并回父节点。后者可能纠正早期贪心选择的局限，但生长后再回退更慢。

A sufficiently deep tree can drive training error to zero but may overfit. Pre-pruning limits depth or requires a minimum number of examples while growing. Post-pruning first grows a large tree, then merges subtrees back into their parents. It can partly repair greedy choices, but growing and then pruning is slower.

Tree strengths and limitations / 树模型的优缺点 · §18.1.5
Strengths / 优点Limitations / 局限
Readable rules; mixed numeric/categorical inputs; invariant to monotone feature transforms; automatic feature selection; fairly robust to outliers; fast and scalable; can handle missing inputs.Predictive accuracy may lag other models; greedy fitting can miss better structures; unstable structure and predictions under small data changes.

缺失值处理：surrogate split 在主切分特征缺失时，用能产生相似分区的相关特征作备用；它是局部、ad hoc 的启发式，不必拟合完整输入联合分布。类别特征也可把 missing 当成新取值。树的不稳定性并非纯缺点：后面的集成章节会利用它。

Missing inputs: a surrogate split uses a correlated feature that produces a similar partition when the primary split feature is missing. It is a local, ad hoc heuristic and need not model the full joint input distribution. For categorical inputs, “missing” can also be treated as a new value. Instability is not only a drawback: later ensemble methods exploit it.

18.2 · ENSEMBLE LEARNING

把多个模型合起来，方差常能下降Combining models can reduce variance

若树的训练结果对样本扰动敏感，它就是高方差估计器。对多个基模型的预测取平均，通常保留相近偏差、降低方差；分类任务也可以多数投票。独立且略好于随机猜测的二分类器投票时，模型数增多会提高多数票正确率。模型错误若强相关，提升会小得多，所以多样性重要。

If a tree changes substantially when the sample changes, it is a high-variance estimator. Averaging base-model predictions often keeps similar bias while reducing variance; classification may also use majority vote. With independent binary classifiers that are slightly better than chance, more voters improve the probability that the majority is correct. Strongly correlated errors reduce this gain, so diversity matters.

\[f(y\mid x)=\frac{1}{|\mathcal M|}\sum_{m\in\mathcal M}f_m(y\mid x),\qquad P(\text{majority correct})=1-B(M/2,M,\theta)\]

这里 \(\theta\) 是单个分类器的正确率，第二式假设各模型错误独立；\(B\) 是二项分布 CDF。书中例子：\(\theta=0.51\) 时，\(M=1000\) 得到约 0.73；\(M=10000\) 约 0.97。这个大提升依赖独立错误假设。

Here \(\theta\) is an individual classifier's accuracy, and the second expression assumes independent errors; \(B\) is the binomial CDF. The text gives about 0.73 for \(\theta=0.51,M=1000\), and about 0.97 for \(M=10000\). That large gain depends on the independence assumption.

Stacking 会学习组合权重Stacking learns how to combine models

Stacking（stacked generalization）把基模型预测加权组合，权重通过单独的数据学习。若直接用基模型的训练集学组合权重，就会让权重集中到该集合上表现最好的单一模型，失去组合意义。

Stacking (stacked generalization) combines base predictions with learned weights. The weights should be learned on separate data; fitting them on the base models' own training set can put all mass on the single model that looks best there.

\[f(y\mid x)=\sum_{m\in\mathcal M}w_m f_m(y\mid x)\]

在教材这里，集成权重 \(w_m\) 可自由设定；它们不是自动得到的模型后验概率。

In this formulation, ensemble weights \(w_m\) are freely chosen; they are not automatically posterior probabilities over models.

集成与 Bayesian model averaging 不同An ensemble is not Bayesian model averaging

BMA 用 \(p(m\mid D)\) 对模型后验预测求和，权重非负且总和为 1。数据趋于无限时，教材说后验会集中到 MAP 模型。集成模型则用可学习的任意 \(w_m\) 组成更大的假设类，不会按这一逻辑自动塌缩到一个 MAP 模型。

BMA sums model posterior predictions using \(p(m\mid D)\); these nonnegative weights sum to 1. As data become infinite, the text says the posterior selects the MAP model. An ensemble instead uses freely chosen \(w_m\) in a larger hypothesis class and does not automatically collapse to one MAP model by that logic.

\[\underbrace{p(y\mid x,\mathbf w,\theta)=\sum_m w_m p(y\mid x,\theta_m)}_{\text{ensemble}}\qquad\ne\qquad\underbrace{p(y\mid x,D)=\sum_m p(m\mid D)p(y\mid x,m,D)}_{\text{BMA}}\]

TAKEAWAYS / 最后记住

把树和集成的逻辑串起来Connect the tree and ensemble ideas

CART 把空间递归切成叶区域，回归叶输出均值、分类叶输出类别分布；它用贪心加权 impurity/MSE 选切分，靠预剪枝或后剪枝限制过拟合。树好解释、能处理混合特征，却可能不够准且对数据扰动不稳定。集成通过平均/投票降低方差；stacking 在单独数据上学组合权重。BMA 使用归一化模型后验，两者不等同。

CART recursively partitions space into leaves; regression leaves predict means, classification leaves store class distributions. Greedy weighted impurity/MSE selects splits, while pre- or post-pruning limits overfit. Trees are interpretable and handle mixed features, but may be less accurate and unstable. Ensembles reduce variance through averaging or voting; stacking learns combination weights on separate data. BMA uses normalized model posteriors, so the two are not the same.
