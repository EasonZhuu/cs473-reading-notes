随机森林与 BoostingRandom Forests and Boosting

随机森林在每个节点随机挑一部分特征来找切分，降低树之间的相似性。Boosting 则逐轮添加弱学习器：平方损失把残差交给下一棵树，AdaBoost 用指数损失加大错分样本权重，LogitBoost 用 log loss 得到概率输出。

Random forests choose a random subset of features at each node, making trees less alike. Boosting adds weak learners in sequence: squared loss sends residuals to the next tree, AdaBoost increases the weight of mistakes under exponential loss, and LogitBoost uses log loss to produce probabilities.

Kevin P. Murphy · Probabilistic Machine Learning: An Introduction · MIT Press 2022 · online edition Apr 18, 2025 · printed pp. 610–616 · PDF pp. 640–646

ONE IDEA / 一个核心想法

两种集成路径：让树更不相似，或逐步修正错误Two ensemble paths: diversify trees or correct errors in sequence

Randomize features / 随机特征

在每个节点的候选特征子集里找最佳切分，让树不总被同一个强特征牵着走。Choose a split from a node-specific feature subset, so trees are not all driven by the same strongest feature.

Add stages / 逐轮相加

保留已学好的部分，只优化新加入的 \(F_m\) 和系数 \(\beta_m\)。Keep earlier components fixed and optimize only the newly added learner \(F_m\) and weight \(\beta_m\).

Choose a loss / 选择损失

平方损失强调残差；指数损失更狠地惩罚错分；log loss 更稳，并支持概率估计。Squared loss targets residuals; exponential loss strongly punishes mistakes; log loss is gentler and supports probability estimates.

阅读边界：这里用一句话回顾 bagging：对重采样数据独立训练多棵树再汇总，作为理解 §18.4 的背景；不展开 §18.3。实验数据都是原创示意，不是教材中的 spam 数据或图表。

Scope: one brief bagging reminder is included as context for §18.4: fit independent trees on resampled data and aggregate them. This note does not cover §18.3. All interactive data are original illustrations, not the textbook spam data or figures.

18.4 · RANDOM FORESTS

随机森林在每个节点随机限制候选特征Random forests randomize the features considered at each node

Bagging 的多棵树需要足够多样。若每棵树都在每个节点检查全部特征，强信号特征可能让它们反复选择相似切分。Random forest 在节点 \(i\) 抽取特征子集 \(S_i\subset\{1,\ldots,D\}\)，只在 \(S_i\) 中优化切分特征 \(j\)；训练样本也具有随机性。这样可进一步降低基学习器的相关性。

Bagging needs diverse trees. If every tree checks every feature at each node, a strong predictor may repeatedly drive the same splits. A random forest samples a node-specific feature set \(S_i\subset\{1,\ldots,D\}\) and optimizes the split feature \(j\) only within \(S_i\); the training cases are also randomized. This can further reduce dependence among base learners.

\[j_i=\arg\min_{j\in S_i,\;t}\; \text{weighted child cost}(j,t)\]

关键变化是候选特征集合 \(S_i\)，节点仍根据当前损失选最佳阈值。

The key change is the candidate set \(S_i\); the node still chooses the threshold that best reduces its current loss.

教材用 spam 分类说明“很多特征无关”时的效果：4601 封邮件有 57 个数值特征，包括 48 个词频、6 个字符比例，以及 3 个大写字母序列统计量。教材图 18.5 的定性结论是，random forest 比 bagged trees 的测试错误低；boosting 在该例中更低，但它必须串行训练树，而随机森林可并行。

The text uses spam classification to illustrate a setting with many irrelevant features: 4,601 emails have 57 numeric features, including 48 word frequencies, 6 character proportions, and 3 statistics of capital-letter runs. Figure 18.5's qualitative result is that random forests have lower test error than bagged trees; boosting is lower still in that example, but must fit trees sequentially while random forests can be parallelized.

取舍：每次看得越少，树通常越容易彼此不同；但若子集太小，强信号特征更容易缺席。特征随机化解决的是树间相似度问题，不保证单棵树变得更准确。

Tradeoff: considering fewer features can make trees less alike, but a very small subset can omit strong predictors more often. Feature randomization targets similarity among trees; it does not guarantee that an individual tree becomes more accurate.

18.5 · BOOSTING

Boosting 逐轮构建加法模型Boosting builds an additive model one stage at a time

\[f_M(x)=\sum_{m=1}^{M}\beta_mF_m(x;\theta_m),\qquad \mathcal{L}(f)=\sum_{i=1}^{N}\ell(y_i,f(x_i))\]

每轮拟合一个新分量 \(F_m\)，再乘以权重 \(\beta_m\) 加到已有预测上。最初的 Boosting 把它用于二分类：只要每个弱学习器在当前加权样本上略好于随机猜测，逐轮组合就能提升准确率。超参数 \(M\) 控制模型复杂度，可根据验证集表现选择并用 early stopping 停止。

Each round fits a new component \(F_m\), weights it by \(\beta_m\), and adds it to the current prediction. The original boosting setup is for binary classification: if each weak learner is slightly better than chance on the current weighted data, sequential combination can improve accuracy. The number of rounds \(M\) controls complexity and can be selected with validation performance and early stopping.

Boosting 的树依赖先前轮次，重点是逐步降低偏差；bagging 和 random forest 独立训练树，更侧重降低方差。因此 Boosting 通常不能像随机森林那样并行拟合所有树。

Boosting trees depend on earlier rounds and mainly reduce bias by correcting the current model. Bagging and random forests fit independent trees and mainly reduce variance. Boosting therefore cannot fit all trees in parallel in the same way as a random forest.

18.5.1 · FORWARD STAGEWISE ADDITIVE MODELING

只优化新分量，冻结过去的模型Optimize the new component and freeze the old ones

\[(\beta_m,\theta_m)=\arg\min_{\beta,\theta}\sum_{i=1}^{N}\ell\!\left(y_i,f_{m-1}(x_i)+\beta F(x_i;\theta)\right)\]
\[f_m(x)=f_{m-1}(x)+\beta_mF_m(x)\]

这叫 forward stagewise additive modeling。第 \(m\) 轮只寻找一个能降低当前目标的新弱学习器和权重；已经加入的 \(F_1,\ldots,F_{m-1}\) 不再回头重调。具体优化取决于损失函数和弱学习器类型。

This is forward stagewise additive modeling. At round \(m\), find a new weak learner and weight that reduce the current objective; do not revisit the parameters of \(F_1,\ldots,F_{m-1}\). The optimization depends on the loss and the form of the weak learner.

18.5.2 · QUADRATIC LOSS AND LEAST SQUARES BOOSTING

平方损失下，新树拟合当前残差With squared loss, the next tree fits current residuals

\[r_{im}=y_i-f_{m-1}(x_i),\qquad F_m\leftarrow\operatorname{fit}(x_i,r_{im}),\qquad f_m=f_{m-1}+F_m\]

代入平方损失后，每个样本的当前误差就是残差 \(r_{im}\)。Least squares boosting 把回归树拟合到这些残差，再把树加到已有模型中；教材的简化推导取 \(\beta_m=1\)。于是新树专门修正旧模型尚未解释的部分。

Under squared loss, the current sample error is its residual \(r_{im}\). Least squares boosting fits a regression tree to these residuals and adds it to the current model; the text's simplified derivation uses \(\beta_m=1\). The new tree therefore targets what the old model has not explained.

Figure 18.6 uses a depth-2 regression tree: the cumulative prediction on the right approaches the data while each new tree on the left fits current residuals. The lab uses original one-dimensional synthetic data and a three-leaf tree to illustrate the same update.

18.5.3 · EXPONENTIAL LOSS AND ADABOOST

指数损失会把错分样本的权重推高Exponential loss raises the weight of misclassified examples

二分类标签记为 \(\tilde y\in\{-1,+1\}\)。当 \(F(x)\) 表示半个 log-odds 时，概率是 \(\sigma(2F(x))\)，log loss 写作 \(\log(1+e^{-2\tilde yF(x)})\)。指数损失 \(e^{-\tilde yF(x)}\) 也是 0–1 loss 的平滑上界；在总体无限样本下，两者的最优概率解相同。

For binary labels \(\tilde y\in\{-1,+1\}\), let \(F(x)\) be half the log-odds, so \(p(y=1\mid x)=\sigma(2F(x))\). The log loss is \(\log(1+e^{-2\tilde yF(x)})\). Exponential loss \(e^{-\tilde yF(x)}\) is also a smooth upper bound on 0–1 loss; in the infinite-sample population setting, both have the same optimal probability solution.

\[\omega_{i,m}=e^{-\tilde y_i f_{m-1}(x_i)},\qquad \operatorname{err}_m=\frac{\sum_i\omega_{i,m}\mathbf{1}[\tilde y_i\ne F_m(x_i)]}{\sum_i\omega_{i,m}}\]
\[\beta_m=\frac12\log\frac{1-\operatorname{err}_m}{\operatorname{err}_m},\qquad \alpha_m=2\beta_m=\log\frac{1-\operatorname{err}_m}{\operatorname{err}_m}\]

离散 AdaBoost 让弱分类器最小化加权错分率。更新后，错分样本权重乘以 \(e^{\alpha_m}\)，正确样本不变；所以后续轮次会更关注前面犯错的样本。要求当前弱学习器至少略好于随机猜测，即加权错误率低于 \(0.5\)。多分类的 SAMME 是指数损失思路的推广。

Discrete AdaBoost chooses a weak classifier that minimizes weighted error. Afterward, a misclassified example's weight is multiplied by \(e^{\alpha_m}\), while a correctly classified example's weight is unchanged. Later rounds focus more on earlier mistakes. The current weak learner should beat chance, so its weighted error is below \(0.5\). SAMME extends the exponential-loss approach to multiclass classification.

Outlier 风险：错分点的指数权重可能迅速变大，因此错误标签或极端 outlier 会主导后续轮次。这个缺点引出下一节的 log-loss 方法。

Outlier risk: exponentially growing weights can make a mislabeled or extreme outlier dominate later rounds. This motivates the log-loss method that follows.

18.5.4 · LOGITBOOST

LogitBoost 用 log loss 缓和极端错分惩罚LogitBoost uses log loss to soften extreme mistake penalties

指数损失对严重错分的惩罚呈指数爆炸，对 outlier 非常敏感；而 \(e^{-\tilde y f}\) 不是二元变量的概率质量函数，因此不能从 \(f(x)\) 直接恢复概率。LogitBoost 改用 log loss，惩罚增长近似线性，并可用 \(p(y=1\mid x)=\sigma(2f(x))\) 得到概率。

Exponential loss grows explosively for severe mistakes and is very sensitive to outliers. Also, \(e^{-\tilde y f}\) is not a binary probability mass function, so it does not directly yield probabilities from \(f(x)\). LogitBoost uses log loss instead: its penalty grows roughly linearly, and \(p(y=1\mid x)=\sigma(2f(x))\) provides probabilities.

\[p(y=1\mid x)=\frac{1}{1+e^{-2f(x)}},\qquad \mathcal{L}_m(F)=\sum_{i=1}^{N}\log\!\left[1+e^{-2\tilde y_i(f_{m-1}(x_i)+F(x_i))}\right]\]

对这个目标做类似 IRLS 的 Newton 更新，可以导出 LogitBoost。关键子程序要求弱学习器能解加权最小二乘问题；这个方法也可推广到多分类。注意教材图 18.7 为展示曲线使用 \(\log_2\)，公式仍按常见 log-loss 记号书写。

A Newton update, similar to IRLS, yields LogitBoost. Its key subroutine requires the weak learner to solve weighted least squares; the method also extends to multiclass settings. Figure 18.7 uses \(\log_2\) to plot the loss curves, while the equations use the usual log-loss notation.

TAKEAWAYS / 最后记住

把随机森林和 Boosting 分清Keep random forests and boosting distinct

Random forest 在节点随机抽候选特征，降低树间相关性，适合特征中有不少无关变量的情形；独立树可并行。Boosting 按损失函数逐轮追加弱学习器，主要通过纠正当前模型来降低偏差。平方损失下拟合残差；指数损失形成 AdaBoost 权重更新，但对 outlier 敏感；log loss 产生 LogitBoost，可提取概率并通过 Newton / IRLS 更新。

Random forests sample candidate features at each node to decorrelate trees, which helps when many features are irrelevant; independent trees can be parallelized. Boosting adds weak learners sequentially according to a loss and mainly reduces bias by correcting the current model. Squared loss fits residuals; exponential loss yields AdaBoost's weight updates but is sensitive to outliers; log loss yields LogitBoost and probability estimates through Newton/IRLS updates.
