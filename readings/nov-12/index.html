THE MAP / 阅读路线

一条训练线，一条解释线One line for training, one for interpretation

1 · Fit

每轮用弱学习器近似当前损失的负梯度。Each round uses a weak learner to approximate the negative gradient of current loss.

2 · Regularize

XGBoost 用二阶统计量打分，并惩罚树叶数与叶权重。XGBoost scores with second-order statistics and penalizes leaf count and leaf weights.

3 · Explain

Gain 汇总分裂改进；PDP 显示固定特征后的平均预测。Gain aggregates split improvement; PDP shows average predictions with selected features fixed.

关键区别：Key distinction: 伪残差是损失对当前预测的负导数；只有平方损失时，它才等于普通残差。A pseudo-residual is the negative loss derivative at the current prediction; only for squared loss does it equal the ordinary residual.

18.5.5 · GRADIENT BOOSTING

梯度提升：在函数空间里逐步下降Gradient boosting: descend through function space

目标是最小化 \(\sum_i L(y_i,f(x_i))\)。第 \(m\) 轮在当前预测处计算每个样本的负梯度，再用弱学习器 \(F_m\) 拟合这些目标。只追加新函数：\(f_m=f_{m-1}+\nu F_m\)，其中 \(0<\nu\le1\) 是 learning rate（shrinkage）。\(\nu\) 较小时每步更谨慎，通常需要更多轮。

The objective is \(\sum_i L(y_i,f(x_i))\). At round \(m\), compute the negative gradient at each current prediction, then fit a weak learner \(F_m\) to those targets. Add only a new function: \(f_m=f_{m-1}+\nu F_m\), where \(0<\nu\le1\) is the learning rate (shrinkage). A smaller \(\nu\) makes each step conservative and usually requires more rounds.

\[r_{im}=-\left.\frac{\partial L(y_i,f(x_i))}{\partial f(x_i)}\right|_{f=f_{m-1}},\quad F_m\approx r_m,\quad f_m=f_{m-1}+\nu F_m\]

样本负梯度给出下降方向；弱学习器近似这个方向。这是普通 gradient descent 的函数空间类比。

Per-example negative gradients give a descent direction; the weak learner approximates it. This is the function-space analogue of gradient descent.

平方误差下负梯度与 \(y_i-f_{m-1}(x_i)\) 成正比，因此回归树拟合残差。其他损失会产生不同的梯度目标。Stochastic gradient boosting 每轮不放回抽取部分样本拟合新树，可减少计算，也可作为随机正则化改善泛化。

With squared error, the negative gradient is proportional to \(y_i-f_{m-1}(x_i)\), so a regression tree fits residuals. Other losses yield different targets. Stochastic gradient boosting draws a without-replacement subsample for each new tree; this can reduce computation and act as regularization.

18.5.5.1 · Gradient tree boosting. 树先把输入划成叶区域 \(R_{jm}\)，再逐叶选输出值使原始损失最小：The tree partitions inputs into leaf regions \(R_{jm}\), then chooses each leaf output to minimize the original loss:
\[\gamma_{jm}=\arg\min_\gamma\sum_{x_i\in R_{jm}}L(y_i,f_{m-1}(x_i)+\gamma)\]

更新为 \(f_m(x)=f_{m-1}(x)+\nu\sum_j\gamma_{jm}\mathbf1[x\in R_{jm}]\)。树确定分区，原损失确定叶输出。

Update with \(f_m(x)=f_{m-1}(x)+\nu\sum_j\gamma_{jm}\mathbf1[x\in R_{jm}]\). The tree defines regions; the original loss determines leaf outputs.

18.5.5.2 · XGBOOST

二阶近似与显式树正则化Second-order approximation and explicit tree regularization

每轮加一棵树 \(f_t\)，目标为 \(\sum_i L(y_i,\hat y_i^{(t-1)}+f_t(x_i))+\Omega(f_t)\)。在旧预测处作二阶 Taylor 展开，得到梯度 \(g_i\) 与 Hessian \(h_i\)。对 \(J\) 个叶子的树，\(\Omega(f)=\gamma J+\frac{\lambda}{2}\sum_jw_j^2\)：\(\gamma\) 惩罚叶数，\(\lambda\) 惩罚叶权重平方。

Add tree \(f_t\) and minimize \(\sum_i L(y_i,\hat y_i^{(t-1)}+f_t(x_i))+\Omega(f_t)\). A second-order Taylor expansion gives gradients \(g_i\) and Hessians \(h_i\). For \(J\) leaves, \(\Omega(f)=\gamma J+\frac{\lambda}{2}\sum_jw_j^2\): \(\gamma\) penalizes leaf count and \(\lambda\) squared leaf weights.

\[G_j=\sum_{i\in I_j}g_i,\quad H_j=\sum_{i\in I_j}h_i,\quad w_j^*=-\frac{G_j}{H_j+\lambda}\]
\[\mathrm{Gain}=\frac12\left(\frac{G_L^2}{H_L+\lambda}+\frac{G_R^2}{H_R+\lambda}-\frac{(G_L+G_R)^2}{H_L+H_R+\lambda}\right)-\gamma\]

正 Gain 才支持切分；非正增益不值得增加复杂度。叶权重是给定分区下的闭式最优值。Positive gain supports a split; nonpositive gain does not justify added complexity. The leaf weight is optimal in closed form for a fixed partition.

还可对子采样行和特征，并使用 out-of-core 计算。下面只计算一个候选二叉切分的局部目标。It also supports row/feature subsampling and out-of-core computation. The lab isolates one candidate binary split's local objective.

18.6.1 · FEATURE IMPORTANCE

特征重要性：汇总节点 split gainFeature importance: aggregate split gain

gain-based importance 对每个特征汇总所有以它切分的节点增益（或先在树间求平均），可将最大值归一化为 100%。它描述切分改进，不是因果效应，也不显示预测方向。样本变化、树选择和相关特征都会影响结果；替代变量也可能分担增益。Gain-based importance sums gains from nodes that split on a feature (or averages across trees), optionally normalizing the maximum to 100%. It describes split improvement—not causality or prediction direction. Samples, tree choices, and correlated features affect it; substitutes may share gain.

教材例子：MNIST 的 0/8 分类把重要性定位到笔画区域；垃圾邮件模型中 “!” 与 “remove” 提高 spam 倾向，“edu” 与 “hp” 降低它。Textbook examples: for MNIST 0-vs-8 classification, importance highlights stroke regions; in the spam model, “!” and “remove” raise spam tendency, while “edu” and “hp” lower it.

18.6.2 · PARTIAL DEPENDENCE

固定目标特征，对其他样本取平均Fix the target feature and average over samples

一维 PDP：\(\bar f_S(x_S)=\frac1N\sum_i f(x_S,x_{i,C})\)。设定目标特征 \(x_S\)，保留各样本的其余特征 \(x_{i,C}\)，预测后取平均。分类常画 log-odds；同时固定两个特征则为二维 PDP。

A one-way PDP is \(\bar f_S(x_S)=\frac1N\sum_i f(x_S,x_{i,C})\). Set \(x_S\), retain each sample's other features, predict, and average. Classification often plots log-odds; fixing two features gives a two-way PDP.

解读提醒：Caveat: PDP 隐去个体差异。相关特征下，强行组合目标值和其余样本可能形成罕见输入；ICE 可显示个体响应。PDP hides individual variation. With correlated features, forced combinations may be rare; ICE reveals individual responses.

教材的 spam 例子显示，增加 “!” 会提高预测的 spam log-odds，“hp” 增加则降低；“!” 的影响在 “hp” 缺失时更强，说明二维 PDP 能显露交互。In the textbook spam example, more “!” raises predicted spam log-odds while more “hp” lowers it; the effect of “!” is stronger when “hp” is absent, illustrating an interaction in the two-way PDP.

TAKEAWAYS / 要点回顾

四条线索Four takeaways

① Gradient boosting 拟合当前负梯度并逐轮加函数；平方损失给出残差拟合。② Gradient tree boosting 在叶区域按原损失优化输出；随机子采样可正则化。③ XGBoost 用二阶统计量与 \(\gamma,\lambda\) 正则化叶和切分。④ Gain importance 汇总切分改进；PDP 平均预测，解释时注意相关特征和个体差异。1. Gradient boosting fits the current negative gradient and adds functions stagewise; squared loss yields residual fitting. 2. Gradient tree boosting optimizes leaf outputs under the original loss; stochastic subsampling can regularize. 3. XGBoost regularizes leaves and splits with second-order statistics and \(\gamma,\lambda\). 4. Gain importance aggregates split improvement; PDP averages predictions, with caveats for correlation and individual variation.
