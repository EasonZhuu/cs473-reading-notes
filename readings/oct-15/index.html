9.3 · NAIVE BAYES CLASSIFIERS

“朴素”是假设给定类别后独立The assumption is independence given the class

先分清两个概率：π꜀=p(y=c) 是看见样本前的类别比例；p(x|y=c) 是这个类别产生各项特征的方式。朴素贝叶斯假设在类别已知时，各个特征条件独立。它没有要求原始数据里的特征无条件独立。

Distinguish the class prior π꜀=p(y=c) from the class-conditional feature model p(x|y=c). Naive Bayes assumes features are conditionally independent given the class. It does not require features to be independent in the pooled population.

\[p(x\mid y=c,\theta)=\prod_{d=1}^D p(x_d\mid y=c,\theta_{dc})\]
\[p(y=c\mid x,\theta)=\frac{\pi_c\prod_d p(x_d\mid y=c,\theta_{dc})}{\sum_{c'}\pi_{c'}\prod_d p(x_d\mid y=c',\theta_{dc'})}\]

先算每类的未归一化分数，再除以所有类别分数之和。特征很多时用 log 避免直接连乘下溢：乘积变成可相加的证据。独立假设常不完全成立，但参数少仍可能带来实用的分类结果；“分类对不对”和“概率准不准”要分开看。

Compute an unnormalized score for each class, then normalize across classes. With many features, use logs to avoid underflow: products become additive evidence. Conditional independence is often imperfect, yet the small model can classify usefully. Classification accuracy and probability calibration are separate questions.

\[s_c=\log\pi_c+\sum_d\log p(x_d\mid y=c),\qquad p(y=c\mid x)=\frac{e^{s_c-m}}{\sum_{c'}e^{s_{c'}-m}},\quad m=\max_{c'}s_{c'}\]

逐项加入、移除证据Add or remove one piece of evidence at a time

1

教学例子：S=垃圾邮件，H=普通邮件。三个二元特征是 free、meeting、link 是否出现。固定 θS=(0.8,0.1,0.7)，θH=(0.1,0.8,0.2)。选择“未观测”会边缘化该特征；选择 0 则明确使用“不出现”的证据。

Teaching example: S=spam and H=ham. Features indicate whether free, meeting, and link appear. Fix θS=(0.8,0.1,0.7) and θH=(0.1,0.8,0.2). Missing marginalizes a feature; 0 explicitly uses its absence as evidence.

An observed 0 is not missing. In a Bernoulli model, presence contributes θ, absence contributes 1−θ, and an unobserved feature sums or integrates to 1, contributing zero in log space.

9.3.2 · MODEL FITTING

标签已知，分别计数就能拟合With labels observed, fit by separate counts and averages

训练数据是 D={(xn,yn)}，类别标签已给出，不需要上次 GMM 的 E-step。联合似然包含类别频率项，以及每个“特征 d × 类别 c”的独立参数项，所以可以分开估计。

Training data D={(xn,yn)} include observed class labels; no GMM-style E-step is required. The joint likelihood separates into a label-frequency term and one parameter block per feature and class, allowing separate estimates.

\[p(D\mid\theta)=\prod_n\left[\pi_{y_n}\prod_d p(x_{nd}\mid y_n,\theta_{d,y_n})\right]\]
\[\log p(D\mid\theta)=\sum_c N_c\log\pi_c+\sum_c\sum_d\sum_{n:y_n=c}\log p(x_{nd}\mid\theta_{dc})\]
\[\hat\pi_c=\frac{N_c}{N},\qquad\hat\theta_{dck}=\frac{N_{dck}}{N_c},\qquad\hat\theta_{dc}=\frac{N_{dc1}}{N_c}\quad\text{(binary)}\]
\[\hat\mu_{dc}=\frac1{N_c}\sum_{n:y_n=c}x_{nd},\qquad\hat\sigma^2_{dc}=\frac1{N_c}\sum_{n:y_n=c}(x_{nd}-\hat\mu_{dc})^2\]

N꜀ 是类别 c 的样本数，Ndck 是其中第 d 项取值 k 的次数。高斯方差的分母是 Nc，这是 MLE，而不是无偏样本方差的 Nc−1。未出现的类别取值会得到零概率；一项为零，整个该类的乘积就为零。

N꜀ counts examples of class c; Ndck counts those whose feature d equals k. Gaussian variance divides by Nc for MLE, rather than Nc−1 for an unbiased sample variance. An unseen categorical value gets zero probability, making the entire class likelihood product zero.

9.3.3 · BAYESIAN NAIVE BAYES

给计数加上先验，再预测Add prior counts, then predict

对每个类别频率 π 和每个分类特征参数 θdc 使用相互独立的 Dirichlet 先验。观测标签已知时，共轭更新只是“先验伪计数 + 观测计数”。二元情况下就是 Beta–Bernoulli。

Use independent Dirichlet priors for class frequencies π and categorical feature parameters θdc. With observed training labels, conjugate updating adds observed counts to prior pseudocounts. The binary case is Beta–Bernoulli.

\[p(\theta\mid D)=\operatorname{Dir}(\pi\mid\hat\alpha)\prod_{d,c}\operatorname{Dir}(\theta_{dc}\mid\hat\beta_{dc}),\qquad\hat\alpha_c=\alpha_c+N_c,\quad\hat\beta_{dck}=\beta_{dck}+N_{dck}\]
\[\bar\pi_c=\frac{\alpha_c+N_c}{\sum_{c'}\alpha_{c'}+N},\qquad\bar\theta_{dck}=\frac{\beta_{dck}+N_{dck}}{\sum_{k'}\beta_{dck'}+N_c}\]
\[\beta_{dck}=1\ \Longrightarrow\ \bar\theta_{dck}=\frac{N_{dck}+1}{N_c+K},\qquad\bar\theta_{dc}=\frac{N_{dc1}+1}{N_c+2}\quad\text{(binary)}\]

这就是 add-one / Laplace smoothing。分母增加 K，因为每个可能取值都加了一个计数。适当的 Dirichlet 参数必须为正；把伪计数设为 0 时，此处使用 MLE 公式或零先验强度的极限，不把 Dirichlet(0) 当作适当先验。

This is add-one or Laplace smoothing. The denominator gains K because every possible state receives a count. Proper Dirichlet parameters are positive. Zero pseudocounts here mean the MLE formula or a limiting zero prior strength, not a proper Dirichlet(0) prior.

\[p(y=c\mid x,D)\propto\bar\pi_c\prod_d p(x_d\mid y=c,D)=\bar\pi_c\prod_d\bar\theta_{dc,x_d}\]

这个单个新样本的预测已经对参数积分。由于后验分解与 categorical likelihood 的形式，结果恰好等同于代入各参数的后验均值；这是本模型的特殊性质，不能据此说任意模型都可用“均值代入”代替积分。

For one new example, this prediction integrates out the parameters. Posterior factorization and the categorical likelihood make it equal to plugging in posterior means. This special property does not justify replacing integration with a mean plug-in in arbitrary models.

9.3.4 · CONNECTION TO LOGISTIC REGRESSION

同样的 softmax 形式，不同的训练目标The same softmax form, different training objectives

对 K 状态的第 d 项特征作 one-hot 编码 xdk=I(xd=k)。因为每项只激活一个取值，categorical NB 的 log 分数是一个对 one-hot 特征的线性函数。γc=log πc，βc 的对应分量是 log θdck。

Encode a K-state feature with xdk=I(xd=k). Each feature activates one state, making categorical NB’s log score linear in the one-hot representation. Its intercept is γc=log πc and its coefficients are the corresponding log θdck.

\[s_c=\log\pi_c+\sum_{d,k}x_{dk}\log\theta_{dck}=\beta_c^\top\phi(x)+\gamma_c,\qquad p(y=c\mid x)=\operatorname{softmax}(s)_c\]

这与 multinomial logistic regression 有同样的后验形式，但 NB 用联合似然学习 π、θ，逻辑回归直接用条件似然学习 β、γ。函数形式一样，不代表同一批数据上拟合出的参数和预测一定相同。

This has the same posterior form as multinomial logistic regression. NB fits π and θ through joint likelihood; logistic regression fits β and γ through conditional likelihood. A shared form does not imply identical fitted parameters or predictions on the same training data.

\[\text{NB: }\max_\theta\sum_n\log p(x_n,y_n\mid\theta),\qquad\text{LR: }\max_{\beta,\gamma}\sum_n\log p(y_n\mid x_n,\beta,\gamma)\]

对同一组 NB 参数，两条计算路线必须相同Two calculations from the same NB parameters must agree

“线性”指对应的特征表示。categorical 模型用 one-hot 特征；一般指数族模型用相应充分统计量。Gaussian NB 若各类方差不同，展开式含 x²，不能据此说它在原始 x 上永远有线性边界。

Linearity refers to the chosen representation: one-hot features for categorical data, or sufficient statistics for other exponential-family likelihoods. Gaussian NB with class-dependent variances includes x² terms, so its boundary need not be linear in raw x.

9.4 + 9.4.1 · GENERATIVE VS DISCRIMINATIVE

生成式学联合，判别式学条件Generative learns the joint; discriminative learns the conditional

\[\text{Generative: }p(x,y)=p(y)p(x\mid y),\qquad\text{Discriminative: }p(y\mid x)\]

生成式分类器可以先选 y，再从 p(x|y) 生成 x，并用 Bayes 规则得到类别后验。判别式分类器直接学 x 到类别概率的关系；单独的 p(y|x) 并不定义怎样生成 x。这里的“生成式”是分类模型的分布分解，不专指生成文本的应用。

A generative classifier can sample a class y and then sample x from p(x|y), using Bayes’ rule for classification. A discriminative classifier directly learns class probabilities from x; p(y|x) alone does not define how to generate x. The term here describes the probability factorization of a classifier.

便于特征预处理 / Flexible feature preprocessing可使用多项式展开、词向量等；生成式模型需解释新特征的联合依赖 / Expansions and embeddings need not come with a tractable generative density

9.4.1 · CALIBRATION

同一条证据，不能当成多条独立证据Copies of one observation are not independent evidence

教学例子：类别先验各半，p(x=1|y=1)=0.8，p(x=1|y=0)=0.2。现在把同一个 x 原样复制 m 份。真实信息没有增加，正确后验仍为 0.8 或 0.2；若 NB 把副本当成独立特征，就会把同一似然比重复乘 m 次。

Teaching example: balanced priors, p(x=1|y=1)=0.8 and p(x=1|y=0)=0.2. Duplicate that exact observation m times. No new information appears, so the true posterior stays 0.8 or 0.2. Treating copies as independent multiplies the same likelihood ratio m times.

\[x=1:\quad\text{true odds}=4,\qquad\text{NB odds}=4^m,\qquad\hat p_{\mathrm{NB}}(y=1\mid x,\ldots,x)=\frac{4^m}{1+4^m}\]

复制特征，看看信心怎样膨胀Duplicate a feature and watch confidence inflate

6

观察分类标签可能一直不变，但概率越来越极端。校准关注的是：给出某个概率的预测，在真实重复样本中是否有相应的正确频率。此处真实条件分布已知，图中的“正确后验”由模型直接给出。

The class decision can stay unchanged while confidence grows extreme. Calibration asks whether predicted probabilities match corresponding frequencies. Here the true conditional distribution is specified analytically, not estimated from a test set.

这说明独立假设失效时，分类仍可能正确而概率明显过度自信。不代表所有生成式模型都无法校准，也不代表任意判别式模型都自动校准良好。

A violated independence assumption can preserve class decisions while producing overconfident probabilities. This does not imply that every generative model is uncalibrated or every discriminative model is automatically calibrated.

与上次 EM 的联系：未标注样本的 y 又变成隐变量，可以在适当的生成式模型中用 EM 来利用它。仅有 p(y|x) 时，对未标注样本把 y 求和永远得到 1，不会自动产生可学习的 p(x) 项，所以需要额外的半监督机制。无标签数据是否有帮助仍取决于模型假设。

Connection to EM: an unlabeled example’s y becomes a hidden variable and can be inferred in a suitable generative model. Summing p(y|x) over y only gives 1, so a conditional model alone does not supply an unlabeled-data p(x) objective; additional semi-supervised machinery is needed. Whether unlabeled data help depends on modeling assumptions.

教材对判别式的优势是“经常”而非“总是”。选择时考虑预测目标、数据量、输入表示、缺失值、概率质量和可用的计算；不能仅凭 generative 或 discriminative 的名字判定哪个一定更好。

The book’s discriminative advantages are tendencies, not universal rankings. Consider the prediction task, data, representation, missing inputs, probability quality, and computation rather than declaring one family always superior.

9.4.3 · HANDLING MISSING FEATURES

没看到的特征，要边缘化Marginalize the feature you did not observe

\[p(y=c\mid x_{\mathrm{obs}})\propto\pi_c\sum_{x_{\mathrm{miss}}}p(x_{\mathrm{obs}},x_{\mathrm{miss}}\mid y=c)\]

连续特征把求和换成积分。一般生成式模型需要实际做边缘化；高斯模型可以使用高斯边缘分布。NB 因为条件独立，可把缺失项单独求和，每项结果为 1，于是只保留已观测的特征因子。

Use an integral for continuous features. General generative models must marginalize their joint density; Gaussian models use Gaussian marginals. Under NB, missing-feature factors sum separately to 1, leaving only factors for observed features.

\[\sum_{x_1}p(x_1,x_{2:D}\mid y=c)=\left[\sum_{x_1}p(x_1\mid y=c)\right]\prod_{d=2}^D p(x_d\mid y=c)=\prod_{d=2}^D p(x_d\mid y=c)\]

回到实验 1，把某项设为“未观测”可检查它的 log 证据变成 0；全部未观测则后验退回类别先验。把缺失值直接填成 0 会错误地加入“特征不出现”的证据。

In experiment 1, setting a feature to Missing makes its log evidence zero. Hiding every feature returns the posterior to the class prior. Filling a missing value with 0 instead adds evidence of absence.

教材在这里假设缺失机制不提供额外信息。若“哪项缺失”本身和类别或潜在值有关，就需要把缺失机制也纳入判断。单独的 p(y|x) 并未规定 p(xmiss|xobs)，所以无法唯一推出缺失输入的边缘预测；实践中可另加插补、缺失指示或相应建模机制。

The book assumes the missingness mechanism adds no relevant information. If missingness itself depends on class or latent feature values, it must be accounted for. A conditional model p(y|x) alone does not specify p(xmiss|xobs), so it does not uniquely determine marginal predictions with missing inputs; imputation, missingness indicators, or other modeling mechanisms supply additional assumptions.
