让“像不像”成为可以学习的距离Learning a Distance That Reflects Similarity

本次从“把训练样本记下来、按邻居投票”的 KNN 出发，再把核心问题往前推一步：如果原始像素或结构化输入里的距离没有语义，能不能先学一个 embedding，让相似样本更近？答案是：训练一个共享的特征提取器，再用 pairwise 或 triplet 排序损失塑造距离。

Start with KNN, which keeps training examples and votes among nearby ones. Then ask a deeper question: if distances in raw pixels or structured inputs do not capture meaning, can we learn an embedding where similar examples are closer? Yes: train a shared feature extractor and shape distances with pairwise or triplet ranking losses.

16.1 · K NEAREST NEIGHBOR CLASSIFICATION

KNN：在附近找例子，再让标签投票KNN: Find nearby examples, then vote

参数模型拟合后通常只留下固定维度的参数；exemplar-based（基于样例）方法则在预测时仍保留训练样本。给新输入 x 找 K 个最近邻，邻居中属于类别 c 的比例就是预测概率。也可以只返回票数最多的类别。KNN 的“模型”由训练数据、K 和距离共同决定。

A fitted parametric model usually keeps a fixed-size parameter vector. An exemplar-based model keeps its training examples at prediction time. For a new input x, find its K nearest neighbors; the fraction with class c is the predicted probability. You may instead return the majority label. The KNN model is determined by its data, K, and distance metric.

\[p(y=c\mid x,\mathcal D)=\frac{1}{K}\sum_{n\in N_K(x,\mathcal D)}\mathbb I(y_n=c)\]

教材的 Figure 16.1 例子里，K=5 的邻居标签是 {1,1,1,0,0}，所以 p(y=1|x,D)=3/5=0.6。K=1 时，每个训练点占据自己的 Voronoi 区域，预测只看最近的一个点，训练误差可为 0；这不等于泛化好。K 增大时，边界通常更平滑、训练误差上升，测试误差可能呈 U 形。教材还指出，N→∞ 时 KNN 的误差可收敛到至多是 Bayes 最优误差的两倍；高维下收敛可能很慢。

In the book’s Figure 16.1, the five labels are {1,1,1,0,0}, giving p(y=1|x,D)=3/5=0.6. With K=1, each training point owns a Voronoi cell and prediction uses one label, so training error can be zero; that does not imply good generalization. As K grows, boundaries usually smooth out and training error rises; test error can be U-shaped. The book also notes that as N→∞, KNN error can approach at most twice the Bayes error; convergence may be slow in high dimensions.

\[d_M(x,x^\prime)=\sqrt{(x-x^\prime)^\mathsf T M(x-x^\prime)},\qquad M\succ 0;\quad M=I\Rightarrow d_M=\text{Euclidean distance}\]

16.1.2 · THE CURSE OF DIMENSIONALITY

维数升高后，“近邻”会变得很远In high dimensions, even a nearest neighbor can be far away

在 D 维单位立方体里，用边长 s 的小立方体覆盖数据比例 p，需要 s^D=p，因此 s=p^(1/D)。D 越大，为了覆盖同一比例，边长越接近 1：局部邻域会吞下很大一片空间。比如 p=0.1、D=10 时，s≈0.79；即使只取 1% 的体积，边长也约为 0.63。

In a D-dimensional unit cube, a cube with side s covers fraction p=s^D, so s=p^(1/D). As D grows, the side needed to cover the same fraction approaches 1: a “local” neighborhood spans much of the space. For p=0.1 and D=10, s≈0.79; even 1% of the volume needs a side of about 0.63.

\[e_D(p)=p^{1/D}\]

这会让近邻变得不够局部，邻居标签不一定能代表查询点。教材给出的两类应对方向是：对目标函数作更强假设（使用参数模型），和/或学习只关注有用维度的距离。深度 metric learning 会先把高维或结构化输入映射到更低维的语义空间。

A neighborhood may cease to be local, so its labels may not predict the query well. The book gives two broad responses: make stronger assumptions about the function with a parametric model, and/or learn a metric that focuses on useful dimensions. Deep metric learning first maps high-dimensional or structured inputs into a lower-dimensional semantic space.

16.1.3 · SPEED AND MEMORY

把样本留在内存，也留下检索成本Keeping examples also keeps a search cost

朴素 KNN 每次查询要计算到 N 个训练点的距离（O(N) 次距离计算），并需保存全部样本。教材介绍的提速思路包括：删去不影响边界的样本、用 k-d tree 或聚类分区、用 locality-sensitive hashing（LSH）或学习到的哈希找候选；FAISS 是稠密向量精确/近似近邻搜索与 K-means 的开源库。

A naive KNN query computes distances to N training examples (O(N) distance evaluations) and stores the examples. The book lists ways to speed it up: prune examples that do not affect boundaries, partition with k-d trees or clustering, or retrieve candidates with locality-sensitive hashing (LSH) or learned hashes. FAISS is an open-source library for exact and approximate nearest-neighbor search and K-means on dense vectors.

策略 / Strategy思路 / Idea需要留意 / Trade-off
样本剪枝 / Pruning删除对边界无影响的 exemplar启发式，结果取决于保留哪些点 / Heuristic; depends on retained points
k-d tree / 聚类 / Partitioning先缩小候选区域 / Restrict the search region高维空间中分区未必有效 / Partitions may help less in high dimensions
LSH / 哈希 / Hashing快速找可能相似的候选 / Retrieve likely candidates quickly近似结果要看索引与数据 / Recall depends on index and data

理解边界：“精确近邻在十维以上不可处理”是教材对常见算法困难的概述，不是所有实现、硬件与数据分布下的定理。近似索引的候选数减少也不自动保证高召回率；需要按具体任务测量。

Interpret the claim carefully: the book describes exact nearest-neighbor search as computationally intractable above about ten dimensions. This is not a theorem covering every implementation, hardware setup, or data distribution. Fewer approximate candidates do not guarantee high recall; evaluate the index on the task.

16.1.4 · OPEN-SET RECOGNITION

最近的已知类别，未必就是正确类别The nearest known class may still be the wrong answer

封闭集假设认为测试时只会出现已知类别。开放集识别允许新类别出现：先找最近的 gallery 样本，再判断相似度是否足够高；低于阈值时拒绝匹配，触发 novelty detection。若确认是新类别，可以加入标签并更新 gallery，这和 incremental / online / lifelong / continual learning 相连。

The closed-world assumption says tests contain only known classes. Open-set recognition allows new classes: find the nearest gallery example, then check whether similarity passes a threshold. If it does not, reject the match and flag novelty. Once the new identity is confirmed, add it to the gallery; this connects to incremental, online, lifelong, or continual learning.

KNN 适合 few-shot 场景，因为每类可以只保存少量、甚至一个样例。Face verification 还要判断两张脸是否为同一人；entity resolution 要判断不同字符串是否指向同一实体；multi-object tracking 要判断新观测来自已有目标还是新目标。OOD detection 则处理与当前任务分布无关的输入。一个“距离过远”的拒绝信号本身并不能区分合法的新类别与 OOD。

KNN fits few-shot settings because a class can be represented by a small gallery, sometimes just one example. Face verification asks whether two faces show the same person; entity resolution asks whether different strings refer to one entity; multi-object tracking asks whether a new observation belongs to an existing target. OOD detection handles inputs unrelated to the task distribution. A distance-based rejection alone cannot tell a valid new class from OOD.

16.2.2 · DEEP METRIC LEARNING

先学表示，再在语义空间里量距离Learn a representation before measuring semantic distance

深度度量学习（DML）用神经网络 e=f(x;θ) 把输入映射成较低维向量，再用相似度训练这个 embedding。常见做法把 e 做 ℓ₂ 归一化，所有点落在单位超球面上。对归一化向量，平方欧氏距离与 cosine similarity 一一对应：一个越小，另一个越大。

Deep metric learning (DML) maps inputs to lower-dimensional vectors e=f(x;θ), then trains the embedding using similarity. A common choice ℓ₂-normalizes e so points lie on the unit hypersphere. For normalized vectors, squared Euclidean distance and cosine similarity are directly related: smaller distance means larger cosine similarity.

\[\hat e_i=\frac{e_i}{\|e_i\|_2},\qquad d(x_i,x_j;\theta)=\|\hat e_i-\hat e_j\|_2^2=2-2\hat e_i^\mathsf T\hat e_j\]

有类别标签时，同类样本可构成 positive pairs、异类可构成 negative pairs；若没有类别标签，也可以通过其他规则产生“相似”对，例如自监督学习中的两种相关视图。学习目标是让正对靠近、负对分开，而不是只保留分类准确率。教材提醒：文献中的 DML 成效比较容易受实验设定影响，本节聚焦较简单、较稳健的方法。

With class labels, same-class examples form positive pairs and different-class examples form negative pairs. Without labels, another rule can create similar pairs, such as related views in self-supervised learning. The goal is to bring positive pairs closer and separate negatives, rather than merely preserve classification accuracy. The book cautions that reported DML gains can depend on experimental comparisons and focuses on simpler, more robust methods.

16.2.3 · CLASSIFICATION LOSSES

分类正确，不代表同类表示会聚在一起Correct classification does not guarantee compact same-class embeddings

一个简单可扩展的办法是先按 C 类标签训练分类器，再拿隐藏层当 embedding；教材提到常取倒数第二层，因为它对新类别可能泛化更好。分类训练约 O(NC)，但它只要求样本落在正确决策边界一侧，不要求同类点彼此接近、异类点彼此远离。没有标签时也无法使用这种监督分类损失。

A simple scalable method is to train a C-class classifier, then reuse its hidden features as the embedding. The book notes that the second-to-last layer is common because it may generalize better to new classes. Classification fitting is O(NC), but only requires points to land on the correct side of a decision boundary; it does not require same-class points to be close or different-class points to be far apart. Without labels, this supervised classification loss is unavailable.

16.2.4.1 · PAIRWISE / CONTRASTIVE LOSS

Siamese：两路输入，共享同一组权重Siamese: two inputs, one shared set of weights

给网络一对输入 (xᵢ,xⱼ)，两条分支都用同一个特征提取器 f(·;θ)，得到嵌入后再量距离。相同类别的 positive pair 要拉近；不同类别的 negative pair 至少要相隔 margin m。两路“孪生”指权重共享，不是训练两个独立网络。朴素地遍历所有 pair 需要 O(N²) 级别的计算；更快的方法在指定范围之外。

Feed a pair (xᵢ,xⱼ) through two branches that use the same feature extractor f(·;θ). Compare the resulting embeddings. Pull positive (same-class) pairs together; push negative (different-class) pairs at least a margin m apart. “Siamese” means shared weights, not two independently trained networks. Naively considering all pairs takes O(N²) work; speedups are outside this assigned range.

16.2.4.2 · TRIPLET LOSS

Triplet：同一个 anchor 同时比较正例和负例Triplet: compare a positive and a negative to one anchor

pairwise loss 分别看正对和负对，二者的损失尺度可能难以比较。Triplet 把 anchor a、相似 positive x⁺、不相似 negative x⁻ 放进同一次比较，要求 anchor-positive 比 anchor-negative 至少近一个 margin。朴素遍历所有三元组需要 O(N³) 级别的计算；实践中常在 minibatch 内组织样本，并确保每个 anchor 有至少一个正例和一个负例。

Pairwise loss treats positive and negative pairs independently, so their loss scales can be hard to compare. A triplet jointly compares an anchor a, a similar positive x⁺, and a dissimilar negative x⁻. It requires the anchor-positive distance to beat the anchor-negative distance by at least a margin. Naively enumerating all triplets takes O(N³) work; in practice, examples are organized into minibatches with at least one positive and one negative for each anchor.

Anchor af(·; θ)êₐ
Positive x⁺f(·; θ)ê₊ · d₊
Negative x⁻f(·; θ)ê₋ · d₋
三支路都共享 θ；一次 loss 同时比较 d(a,x⁺) 与 d(a,x⁻)。
All three branches share θ; one loss compares d(a,x⁺) and d(a,x⁻) together.
\[\mathcal L_{\text{triplet}}=[d_\theta(a,x^+)^2-d_\theta(a,x^-)^2+m]_+,\qquad \mathcal L=0\iff d_-^2\ge d_+^2+m\]

16.2.4.3 · N-PAIRS LOSS

N-pairs：一个 anchor 对比多个负例N-pairs: compare one anchor with multiple negatives

Triplet 每次只比较一个 negative，可能信号不够强。N-pairs 为 anchor 配一个 positive 和一组 N−1 个 negatives，把“positive 的 cosine 相似度高于所有 negatives”写成多类 softmax / 对数损失。书中指出，N-pairs loss 与 InfoNCE 相同；对比相似度再加 temperature scaling 的版本称为 NT-Xent。

A triplet compares only one negative at a time, which may provide a weak signal. N-pairs gives each anchor one positive and a set of N−1 negatives, then uses a multiclass softmax / log loss to make the positive cosine similarity outrank all negatives. The book identifies N-pairs loss with InfoNCE; a temperature-scaled similarity version is called NT-Xent.

\[\mathcal L_{\text{N-pairs}}=\log\left(1+\sum_{k=1}^{N-1}\exp\left(\hat e(x)^\mathsf T\hat e(x_k^-)-\hat e(x)^\mathsf T\hat e(x^+)\right)\right)\]

N=2 时只有一个负例，损失化为 logistic 形式 log(1+exp(s₋−s₊))。这和 triplet hinge loss 用的是不同函数形状：一个平滑 logistic，一个 max(0,·) hinge；教材在 m=1 时给出对应的 cosine margin 形式。temperature τ 把相似度差除以 τ；它改变竞争的尖锐程度，不改变正负对的语义定义。

When N=2, there is one negative and the loss reduces to the logistic form log(1+exp(s₋−s₊)). This differs from the triplet hinge max(0,·): logistic is smooth, while hinge is piecewise linear; the book gives the corresponding cosine margin form for m=1. Temperature τ divides similarity differences by τ; it changes how sharply candidates compete, not which pairs are semantically positive or negative.

KNN 把标签投票交给邻域；高维会让邻域不再局部，检索还要保留和搜索大量样本。深度 metric learning 先把输入编码成归一化 embedding。分类损失只塑造分类边界；pairwise contrastive loss 在 Siamese 共享网络里按 margin 拉近正对、推开负对；triplet loss 对同一 anchor 联合比较正负距离；N-pairs 则一次对比多个 negatives。

KNN votes over a neighborhood; high dimensions can make that neighborhood nonlocal, and retrieval requires storing and searching many examples. Deep metric learning first encodes inputs as normalized embeddings. Classification loss shapes a decision boundary only. Pairwise contrastive loss pulls positives and pushes negatives by a margin in a shared Siamese network; triplet loss compares positive and negative distances to one anchor; N-pairs compares multiple negatives at once.
