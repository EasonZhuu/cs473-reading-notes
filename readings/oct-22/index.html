给每个样本一座小山A Small Hill for Every Data Point

核密度估计（KDE）把每个观测点变成一个平滑的小核，再把这些小核平均起来，得到概率密度曲线。调节带宽，就是调节每座小山的宽窄。

Kernel density estimation (KDE) places a smooth bump at every observation and averages the bumps into a probability density. The bandwidth controls each bump’s width.

ONE IDEA / 一个核心想法

把离散样本变成连续密度Turn samples into a continuous density

给定样本 \(x_1,\ldots,x_N\)，KDE 在每个 \(x_n\) 周围放一个归一化密度核 \(K_h(x-x_n)\)，然后求平均。它是生成式模型：可在任意位置计算 \(p(x)\)，也可均匀抽一个样本点，再从该点周围的核中生成新样本。

Given observations \(x_1,\ldots,x_N\), KDE places a normalized density kernel \(K_h(x-x_n)\) at each \(x_n\) and averages them. It is generative: evaluate \(p(x)\) anywhere, or draw a data point uniformly and sample from its kernel.

\[ \widehat p(x\mid D)=\frac{1}{N}\sum_{n=1}^{N}K_h(x-x_n) \]
One point, one bump / 一点一座小山

每个核积分为 1；平均后，KDE 总面积仍为 1。

Each kernel integrates to one, so the average KDE also has unit area.

Nonparametric / 非参数

样本直接作为中心；预测时要保留这些观测。

The observations are the centers and must be retained for prediction.

Bandwidth / 带宽 \(h\)

小 \(h\) 保留细节；大 \(h\) 会平滑并合并邻近结构。

Small \(h\) preserves detail; large \(h\) smooths and merges nearby structure.

16.3.1 · DENSITY KERNELS

密度核要满足什么？What makes a density kernel?

一维密度核 \(K:\mathbb R\to\mathbb R_+\) 非负、积分为 1，并关于 0 对称。对称性使均值为 0；平移到 \(x_n\) 后，均值就是 \(x_n\)。带宽缩放 \(K_h(u)=\frac1hK(u/h)\) 同时拉宽横轴并降低高度，以保持面积为 1。\(D\) 维推广可用径向基函数 \(K_h(x)\propto K(\|x\|/h)\)；高斯核的归一化因子是 \(h^D(2\pi)^{D/2}\)。

A 1D density kernel \(K:\mathbb R\to\mathbb R_+\) is nonnegative, integrates to one, and is symmetric about zero. Symmetry gives mean zero; shifting it to \(x_n\) gives mean \(x_n\). Bandwidth scaling \(K_h(u)=\frac1hK(u/h)\) stretches the axis and lowers the height to preserve unit area. In \(D\) dimensions, a radial basis kernel depends on \(\|x\|/h\); the Gaussian normalization contains \(h^D(2\pi)^{D/2}\).

\[ K_h(u)=\frac{1}{h}K\!\left(\frac{u}{h}\right),\qquad \int K_h(u)\,du=1 \]
\[ K_h(x)=\frac{1}{h^D(2\pi)^{D/2}}\exp\!\left(-\frac{\|x\|^2}{2h^2}\right)\quad\text{(D-dimensional Gaussian)} \]

这里的 kernel 是统计密度核。Mercer kernel（§17.1）和卷积核是另两种概念。

Here, “kernel” means a statistical density kernel. Mercer kernels (§17.1) and convolution filters are different concepts.

Gaussian / 高斯

无界支撑、处处平滑，远处权重逐渐变小。

Unbounded support and smooth everywhere, with gradually diminishing tails.

Boxcar / 矩形

只在 \(|u|\le1\) 非零；支撑紧凑，但边缘有跳变。

Nonzero only for \(|u|\le1\); compact support with jumps at the boundary.

Epanechnikov / Tri-cube

紧支撑且平滑；Tri-cube 在支撑边缘也可微。

Smooth compact-support kernels; tri-cube is differentiable at its support boundary too.

16.3.2 · PARZEN WINDOW ESTIMATOR

Parzen 窗：把小核叠起来Parzen windows: add up the bumps

固定等权、固定球形协方差的高斯混合模型，若把每个样本都设为一个中心，就得到 KDE。它不用拟合有限个中心或选择簇数（仍需选择 \(h\)）；代价是要保留所有数据，而且每次评估都要计算各样本的贡献。

A Gaussian mixture with equal weights and fixed spherical covariance becomes KDE when every observation is a center. KDE avoids fitting a finite set of centers or choosing the number of clusters (but still needs \(h\)); it must store all data and evaluate their contributions at prediction time.

\[ \widehat p(x\mid D)=\frac{1}{N}\sum_{n=1}^{N}K_h(x-x_n) \quad\text{(Parzen window density estimator)} \]

矩形核会数窗口中的样本，得到分段常数曲线；高斯核产生平滑小山。核形状与带宽共同决定密度外观。

A boxcar counts points in a window and makes a piecewise-constant curve; a Gaussian gives smooth bumps. Kernel shape and bandwidth jointly determine the estimate.

16.3.3 · BANDWIDTH SELECTION

带宽控制模型复杂度Bandwidth controls model complexity

带宽过小会留下许多尖峰；带宽过大会抹平真实局部结构。对一维高斯核、假设真实分布为高斯，频率学派风险最小化给出的参考值是 \(h=\sigma(4/(3N))^{1/5}\)。它依赖这些假设，并非对所有数据都最优。

Too little bandwidth leaves many sharp bumps; too much washes out local structure. For a 1D Gaussian kernel and a Gaussian true distribution, minimizing frequentist risk gives \(h=\sigma(4/(3N))^{1/5}\). This rule depends on those assumptions and is not universally optimal.

\[ h_{\rm rule}=\sigma\left(\frac{4}{3N}\right)^{1/5},\qquad \widehat\sigma_{\rm robust}=1.4826\,\mathrm{MAD} \]

为降低离群值影响，可用 \(\mathrm{MAD}=\mathrm{median}(|x-\mathrm{median}(x)|)\)，再取 \(\widehat\sigma=1.4826\,\mathrm{MAD}\)。在 \(D\) 维分别估计 \(h_d\)，再用几何平均 \(h=(\prod_dh_d)^{1/D}\)。

To reduce sensitivity to outliers, use \(\mathrm{MAD}=\mathrm{median}(|x-\mathrm{median}(x)|)\), then \(\widehat\sigma=1.4826\,\mathrm{MAD}\). In \(D\) dimensions, estimate each \(h_d\) separately and combine them with the geometric mean \(h=(\prod_dh_d)^{1/D}\).

16.3.4 · FROM KDE TO KNN

KNN 投票是自适应 KDEKNN voting as an adaptive KDE

固定带宽使用同样大小的窗口。Balloon KDE 则围绕查询 \(x\) 扩大体积 \(V(x)\)，直到找到共 \(K\) 个点（不论类别）。记窗口内类别 \(c\) 的点数为 \(N_c(x)\)，全体数据中的该类数量为 \(N_c\)。结合类别先验后，共同窗口体积和类频率抵消，后验就等于邻域内该类的比例。

A fixed bandwidth uses same-size windows. Balloon KDE expands a volume \(V(x)\) around query \(x\) until it contains \(K\) points, regardless of class. Let \(N_c(x)\) count class-\(c\) points inside and \(N_c\) count that class in all data. Combining the class prior cancels the shared volume and class frequency, leaving the class fraction in the neighborhood.

\[ \widehat p(x\mid y=c,D)=\frac{N_c(x)}{N_cV(x)},\qquad p(y=c)=\frac{N_c}{N} \]
\[ \widehat p(y=c\mid x,D)=\frac{N_c(x)}{K}=\frac1K\sum_{n\in\mathcal N_K(x,D)}\mathbb I(y_n=c) \]

这是 KNN 的生成式解释：邻域标签频率估计后验，多数类是最大后验类别；邻域体积会随局部稀疏程度调整。

This is a generative explanation of KNN: neighborhood label frequencies estimate the posterior, and the majority class is the MAP class. The neighborhood volume adapts to local density.

16.3.5 · KERNEL REGRESSION

用邻近样本预测连续值Predict continuous values from nearby samples

用 KDE 估计联合密度 \(p(x,y\mid D)\)，对 \(y\) 条件化并积分，得到 Nadaraya–Watson（N–W）估计。输入 \(x_n\) 越靠近查询点，输出 \(y_n\) 权重越大；归一化权重非负且总和为 1。

Estimate the joint density \(p(x,y\mid D)\) with KDE, condition on \(x\), then integrate over \(y\). This gives the Nadaraya–Watson (N–W) estimate: nearby inputs \(x_n\) give their responses \(y_n\) more weight. Normalized weights are nonnegative and sum to one.

\[ \widehat p(x,y\mid D)=\frac1N\sum_{n=1}^{N}K_h(x-x_n)K_h(y-y_n) \]
\[ \mu(x)=\mathbb E[y\mid x,D]=\sum_{n=1}^{N}w_n(x)y_n,\qquad w_n(x)=\frac{K_h(x-x_n)}{\sum_{n'=1}^{N}K_h(x-x_{n'})} \]

若输出方向也用方差为 \(\sigma_y^2\) 的高斯核，可估计预测方差：\(\mathrm{Var}[y\mid x,D]=\sigma_y^2+\sum_nw_n(x)y_n^2-\mu(x)^2\)。它包含输出核自身的方差。

If the output dimension uses a Gaussian kernel with variance \(\sigma_y^2\), predictive variance is \(\mathrm{Var}[y\mid x,D]=\sigma_y^2+\sum_nw_n(x)y_n^2-\mu(x)^2\). This includes variance from the output kernel itself.

LOWESS / LOESS 不直接对 \(y_n\) 做归一化加权平均，而是在查询点周围拟合加权直线：\(\min_\beta\sum_n[y_n-\beta^\top\phi(x_n)]^2K_h(x-x_n)\)，其中 \(\phi(x)=[1,x]^\top\)。它常用于散点图的局部趋势线。

LOWESS / LOESS fits a weighted line near the query instead of averaging the \(y_n\) values: \(\min_\beta\sum_n[y_n-\beta^\top\phi(x_n)]^2K_h(x-x_n)\), where \(\phi(x)=[1,x]^\top\). It is often used for local trend lines on scatterplots.

TAKEAWAYS / 带走这几句

一条密度曲线，几种解释One density curve, several views

KDE 给每个样本放一个归一化核再取平均；带宽定平滑尺度，核形状定局部权重。窗口扩张到 K 个点时，类别后验就是邻居比例，即 KNN。按输入邻近度加权平均输出是 N–W 回归；在邻域拟合直线则是 LOWESS / LOESS。

KDE averages one normalized kernel per observation. Bandwidth sets smoothing scale; kernel shape sets local weights. Expanding a window to K points makes the class posterior the neighbor fraction: KNN. A proximity-weighted response average is N–W regression; a locally fitted line is LOWESS / LOESS.
